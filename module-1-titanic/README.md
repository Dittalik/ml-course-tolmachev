## Результаты обучения моделей

**Дата обучения:** 28 октября 2026 года

В рамках проекта были обучены и оценены две модели классификации:

- Logistic Regression — логистическая регрессия.
- Decision Tree — дерево решений.

### Сохранённые артефакты

Обученные модели, масштабировщик признаков, кодировщик пола, список используемых признаков и метрики сохранены в директории `models/`.

Для воспроизводимости эксперимента используется фиксированное значение `random_state=42` при разбиении данных и обучении моделей, где это предусмотрено параметрами алгоритма.
